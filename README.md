## Features

- Learn the numbers 0&ndash;9 by listening and tapping the matching digit.
- Every correct answer grows a plant as a reward.
- Real human voices in 5 languages.
- Fully offline &mdash; no internet, no accounts, no ads.
- Kid-safe &mdash; no tracking, no in-app purchases.
- Free and open source under the Apache 2.0 license.
